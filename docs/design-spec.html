หมายเหตุการใช้งาน

พิมพ์เขียวนี้เป็น guideline ไม่ใช่สเปคตายตัว — ปรับได้ตามจริงตอน implement

  • สี: เขียว = กำไร, แดง = ขาดทุน, น้ำเงิน = action/active — ใช้ token จาก shadcn ได้เลย
  • หลาย component ซ้ำกัน (การ์ดสถิติ, ตาราง, ฟอร์ม modal) — ทำเป็น reusable component ครั้งเดียวใช้ได้ทุก project
  • กราฟทั้งหมดใช้ Recharts (มากับ ecosystem React อยู่แล้ว)
  • หน้า login เป็น pattern กลาง ใช้ได้ทั้ง 3 project แค่เปลี่ยนชื่อ+ไอคอน
  • เริ่ม implement หน้าไหนก่อนก็ได้ แต่แนะนำ login → list → form → dashboard (dashboard ต้องมีข้อมูลก่อนถึงเห็นผล)
