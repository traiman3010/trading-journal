## ⚠️ Anti-Patterns ที่ต้องเลี่ยง

### ❌ Don't:
- List every tech you've used (waters down signal)
- Add "Open Source Contributor" if no real contributions
- Use AI-generated boilerplate (recruiters can tell)
- Add memes / emojis everywhere (unprofessional)
- Brag about easy projects
- Out-of-date status ("Currently learning React" if you're advanced)

### ✅ Do:
- Show 2-3 best projects prominently
- Concrete metrics ("processes 100 trades/sec")
- Live demo links
- Update at major milestones (every 2 months)
- Honest level ("learning", "comfortable", "expert")
- Clear path/direction
