Tier 3 · ทำไมข้าม design

Tier 3 ไม่มี design spec โดยตั้งใจ

Tier 3 คือการยกระดับเป็น production (Docker, CI/CD, caching, monitoring, testing) ซึ่งเป็นงาน infra ที่ไม่เพิ่มหน้าจอใหม่ให้ผู้ใช้ ส่วน dashboard ของ monitoring มักใช้เครื่องมือสำเร็จรูป (Sentry, Grafana) ที่มี UI มาให้แล้ว ไม่ต้องออกแบบเอง — ดูรายละเอียดใน 06-production-grade-guide.md
